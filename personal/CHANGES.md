# DroidDeck Personal (work in progress)

Upstream: https://github.com/Droid-Deck/DroidDeck at fdf3d98c36c35c2d770ec54e59f3dd424f212beb, GPL-3.0; upstream notices and licences remain in the source tree. DroidDeck Personal source: https://github.com/Zeknes/droiddeck-personal. FusionHUD by The412Banner: https://github.com/The412Banner/FusionHUD.

Changes: independent Android application ID `com.zeknes.droiddeckpersonal`, app name and icon; desktop selected by default, game/store/soundtrack navigation tabs and game deep links removed; emulator pages suppressed; desktop startup no longer generates Steam icons, runs the game inventory, or switches to Steam after Plasma exits. Steam guest relaunch requests and account readiness settings removed. App startup no longer initializes or registers game-store backends; session startup no longer starts game-store request watchers or Epic synchronization, and session teardown no longer uploads game cloud saves or refreshes store libraries. Storage scanning no longer scans game store folders. Xbox, GOG Comet, Ubisoft and Rockstar helper build stages and the Xbox, Comet and Ubisoft packs are omitted. The Rust game-store build and native loader are removed; tracking and butler packs are omitted, as their callers are hand-tracking and itch game downloads respectively. PowerVR is retained because the desktop's system Vulkan graphics path uses it. DirectAudio Wine pack remains. Epic, GOG, Amazon, EA and Ubisoft Android store backends, game library/store screens, native store bridge, cloud saves and achievement integration are removed. Some game-related source, data models, assets, dependencies and settings remain; they are not claimed as removed. No independent terminal mode yet; KDE's Konsole uses the same guest environment.

Second pass (versionCode 22, 0.7.2): Xbox cloud streaming is removed end to end - the `stores/xbox` package and its WebRTC player activities, the `io.github.webrtc-sdk` dependency that bundled `libjingle_peerconnection_so.so`, the bundled xCloud web player assets and the `tools/xcloud-player` sources. Quest/OpenXR support is removed: `QuestXrActivity` and the `droiddeckxr` native activity, the OpenXR loader dependency, `session/QuestExperimental` with its automatic Quest GPU-driver defaults, the Quest-only Vulkan driver packs (`adrenotools-turnip25.1.0-quest1`, `adrenotools-turnip26.3.0-quest2`), the Oculus manifest metadata and the `android.hardware.vr.headtracking` feature. The Adreno 6xx fallback pack that the Quest packaging script also produced stays, now built by `tools/a6xx-driver/build-driver.py`. SteamVR started from a session and the smart-glasses path remain, as do the game-store backends, game library and soundtrack code described above.

The upstream runtime catalog currently points to Ubuntu 26.04 LTS ARM64 release candidate `ubuntu-r1-rc5` (291553163 bytes, SHA-256 `434d3d91f9c93d94deebbbdc57a1b3763443f785925393f15db19feed477e030`). The catalog is mutable, so this is not a pinned runtime. KDE pack build pin `desktop-kde-r3`: SHA-256 `8b7142fcec8d86143ae39fc14ffc86907d30d9a5b5a45f49cb1b55109d6fc4eb`, 972598429 bytes. The actual desktop package is selected from the installed rootfs `usr/share/droiddeck/desktop-pack.json` before falling back to the Arch KDE pin; for the Ubuntu runtime this selects `ubuntu-r1-rc5-desktop`, size 898306226, SHA-256 `e676968a8dc5f3817061731008f877be860e29cc6d017b3170d192513d584de2`. Both archives were downloaded from the upstream release and their SHA-256 values matched the catalog. Rootfs identifies itself as Ubuntu 26.04.1 LTS and includes apt-get; desktop archive contains Konsole, KWin, startplasma-wayland and package copyright files. Ubuntu package handling uses dpkg metadata. Runtime/desktop installation, actual package management and SSH remain to be tested.

PRoot, Wayland, display, input, clipboard, audio and graphics paths remain upstream. KWin defaults to software rendering; an upstream optional OpenGL/Zink path also exists. No device performance claim is made.
