# DroidDeck Pure

The only offered and launched desktop is Plasma Mobile. Version 0.7.9 (Android versionCode 38) stages the app's own session scripts again after a desktop pack extraction and is distributed from clean main and retains the independent application ID `com.zeknes.droiddeck.pure`, retaining the accepted Mobile keyboard fixes. Other desktop environment entries and installers are not offered; shared KDE/Plasma/KWin dependencies remain. GNOME development is discontinued. Pure can coexist with the historical `com.zeknes.droiddeck.mobileprobe` installation and has separate private data and runtime; no automatic migration, uninstall or data clearing is performed. Pure keeps the existing signing key for future Pure upgrades; internal namespaces and runtime command names remain compatible.

Upstream: https://github.com/Droid-Deck/DroidDeck at fdf3d98c36c35c2d770ec54e59f3dd424f212beb, GPL-3.0; upstream notices and licences remain in the source tree. DroidDeck Pure source: https://github.com/Zeknes/droiddeck-pure. FusionHUD by The412Banner: https://github.com/The412Banner/FusionHUD.

Changes: movable Android-hosted Plasma navigation with Back/Home/Overview/Keyboard, six-second idle collapse to a visible wake handle, persisted safe placement and 48 dp touch targets; the Mobile shell alone uses software Qt rendering after an observed Zink dmabuf import crash, while KWin/app GPU settings remain intact. Bounded native-guest CPU/GPU diagnostics with a Plasma application entry, JSON/HTML output, thermal guards and explicit distinction between guest FPS and Android presentation; opt-in loopback-only key-authenticated guest SSH with a narrowly scoped PRoot SFTP return-value adapter. Existing guest data and keys are retained. The corner build watermark is hidden by default and after resetting settings; explicit on/off choices, the Updates-page toggle and real build details remain available. Independent Android application ID `com.zeknes.droiddeck.pure`, app name and icon; desktop selected by default, game/store/soundtrack navigation tabs and game deep links removed; emulator pages suppressed; desktop startup no longer generates Steam icons, runs the game inventory, or switches to Steam after Plasma exits. Steam guest relaunch requests and account readiness settings removed. App startup no longer initializes or registers game-store backends; session startup no longer starts game-store request watchers or Epic synchronization, and session teardown no longer uploads game cloud saves or refreshes store libraries. Storage scanning no longer scans game store folders. Xbox, GOG Comet, Ubisoft and Rockstar helper build stages and the Xbox, Comet and Ubisoft packs are omitted. The Rust game-store build and native loader are removed; tracking and butler packs are omitted, as their callers are hand-tracking and itch game downloads respectively. PowerVR is retained because the desktop's system Vulkan graphics path uses it. DirectAudio Wine pack remains. Epic, GOG, Amazon, EA and Ubisoft Android store backends, game library/store screens, native store bridge, cloud saves and achievement integration are removed. Some game-related source, data models, assets, dependencies and settings remain; they are not claimed as removed. No independent terminal mode yet; KDE's Konsole uses the same guest environment.

The upstream runtime catalog currently points to Ubuntu 26.04 LTS ARM64 release candidate `ubuntu-r1-rc5` (291553163 bytes, SHA-256 `434d3d91f9c93d94deebbbdc57a1b3763443f785925393f15db19feed477e030`). The catalog is mutable, so this is not a pinned runtime. KDE pack build pin `desktop-kde-r3`: SHA-256 `8b7142fcec8d86143ae39fc14ffc86907d30d9a5b5a45f49cb1b55109d6fc4eb`, 972598429 bytes. The actual desktop package is selected from the installed rootfs `usr/share/droiddeck/desktop-pack.json` before falling back to the Arch KDE pin; for the Ubuntu runtime this selects `ubuntu-r1-rc5-desktop`, size 898306226, SHA-256 `e676968a8dc5f3817061731008f877be860e29cc6d017b3170d192513d584de2`. Both archives were downloaded from the upstream release and their SHA-256 values matched the catalog. Rootfs identifies itself as Ubuntu 26.04.1 LTS and includes apt-get; desktop archive contains Konsole, KWin, startplasma-wayland and package copyright files. Ubuntu package handling uses dpkg metadata. The Plasma Mobile route and keyboard fixes were accepted by the user; this new independent package has not been installed on a device during the rename.

PRoot, Wayland, display, input, clipboard, audio and graphics paths remain upstream. KWin defaults to software rendering; an upstream optional OpenGL/Zink path also exists. No device performance claim is made.
